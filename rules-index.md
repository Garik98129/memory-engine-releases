# Topic rules — release v0.1.17

The rules of release v0.1.17: which files to read, and when. Read them in the repository `grafyla/releases` at the tag `v0.1.17` — ref `v0.1.17`. Not at the branch this index came from: the branch moves on to the next release, the tag never moves.

These rules are written for the engine of release `v0.1.14` or newer in the user's repository. That line is for that repository's checks: a chat cannot see that repository and does nothing about it.

Before you answer or act on a topic, read every file of its line in full — all of them, once a conversation. The files name each other's rules; read the ones this index lists, not the ones a file mentions.

A topic applies when the talk is about the user, the user's family or the user's own pets. A general question — about a breed, somebody else's animal — needs no rules: answer it as you would anyone; what the user personally wants to read, watch, listen to, visit, try or buy is the user's — the topic «notes and ideas»; the user's own affairs and projects, with what was decided in them, are the user's too — the topic «affairs and projects». Not clear whose it is → one question.
